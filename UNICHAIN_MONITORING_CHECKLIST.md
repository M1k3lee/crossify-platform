# Unichain Monitoring Checklist

## 🔍 How to Monitor for Unichain Launch

### Official Sources

1. **Unichain Website**
   - URL: https://unichain.org
   - Check: Weekly for updates
   - Look for: Testnet/mainnet announcements

2. **Uniswap Labs Blog**
   - URL: https://blog.uniswap.org
   - Check: For Unichain announcements
   - Look for: Launch dates, testnet access

3. **Unichain Documentation**
   - URL: https://docs.unichain.org
   - Check: For technical details
   - Look for: RPC endpoints, chain IDs

4. **Unichain Social Media**
   - Twitter/X: @Unichain (if exists)
   - Discord: Unichain community
   - Telegram: Unichain announcements

### What to Watch For

- [ ] Testnet launch announcement
- [ ] Mainnet launch date
- [ ] RPC endpoint URLs
- [ ] Chain ID numbers
- [ ] Block explorer URLs
- [ ] LayerZero endpoint (if supported)
- [ ] Documentation updates

### When Testnet Launches

1. **Get Testnet Access**
   - Request testnet tokens
   - Get RPC endpoint
   - Test deployment

2. **Update Code**
   - Update Hardhat config with real values
   - Update frontend config
   - Deploy contracts

3. **Test Everything**
   - Token creation
   - Price sync
   - v4 graduation
   - Cross-chain messaging

### When Mainnet Launches

1. **Deploy to Mainnet**
   - Deploy all contracts
   - Configure cross-chain
   - Enable for users

2. **Market Aggressively**
   - Press release
   - Social media
   - Community announcements

3. **Monitor & Optimize**
   - Watch for issues
   - Fix quickly
   - Gather feedback
