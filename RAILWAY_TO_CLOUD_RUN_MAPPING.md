**DO NOT use the Railway DATABASE_URL!**

Instead, after connecting Cloud SQL, use:
- **Name:** `DATABASE_URL`
- **Value:** `postgresql://postgres:YOUR_PASSWORD@/crossify-db?host=/cloudsql/voltaic-wall-480423-u9:europe-west2:crossify-db`
